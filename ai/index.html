Learn each topic, build a project that uses it, then move on. By the end you'll have a deployed capstone project for your resume.

Versions
Checked against official docs when each lesson is written

How the course works

Every module follows the same three steps:

  1. Topics: one concept per lesson, taught from the ground up, with exercises that check your answers instantly.
  2. Module project: a real program that combines everything from that module's topics.
  3. Next module: it builds on the last one.

This is a plan, not a contract. The order and pace adjust to how your lessons go.

Modules

1 · Python basics

12 topics + project · ≈ 4–5 weeks
  1. Running Python: interactive mode, numbers, your first script
  2. Variables and strings: naming, text, f-strings, input()
  3. True/False and if/else: comparisons, and/or/not, blocks
  4. Lists and loops: indexing, split/join, for, range, while
  5. Dictionaries, tuples and sets
  6. Functions
  7. Built-in functions and comprehensions
  8. Errors and exceptions
  9. Files and JSON
  10. Modules, packages and uv (Python's npm)
  11. Classes and dataclasses
  12. Type hints
Project: job-radar, a command-line tool that reads AI job postings and reports the most in-demand skills.

2 · Python for web and APIs

≈ 2–3 weeks
  • Calling web APIs with httpx
  • async/await
  • Pydantic (data validation, used everywhere in LLM apps)
  • FastAPI (building your own API)
Project: turn job-radar into a web API.

3 · LLM fundamentals

≈ 4–5 weeks
  • What an LLM is: tokens, context and temperature
  • Running a model on your own machine (Ollama / LM Studio)
  • Calling a free-tier model API
  • Prompting and structured output
  • Tool calling
  • Embeddings and vector search
  • RAG (retrieval-augmented generation)
  • Evals: proving your app works
Project: an LLM that extracts skills from postings and answers questions about them.

4 · LangChain and LangGraph

≈ 2–3 weeks
  • LangChain 1.x: models, messages and tools
  • Agents with create_agent (the current API, docs)
  • LangGraph: state, memory, human-in-the-loop
  • Agents and MCP
Project: an agent version of job-radar.

5 · Classic machine learning

≈ 3 weeks
  • NumPy and pandas
  • scikit-learn: regression and classification
  • Train/test splits, metrics, overfitting
Project: a classifier that predicts a posting's seniority.

6 · Neural networks from scratch

≈ 3–4 weeks
  • PyTorch tensors and autograd
  • Training loops, loss and gradient descent
  • A tiny GPT, following Karpathy's Zero to Hero
Project: train a small language model on a free cloud GPU.

7 · Fine-tuning open models

≈ 2–3 weeks
  • Hugging Face: Transformers, Datasets, the Hub
  • LoRA fine-tuning with Unsloth on a free GPU
  • When to fine-tune, and when to use RAG or better prompts instead
Project: fine-tune a small model and publish it to Hugging Face.

8 · Capstone

≈ 3–4 weeks
  • Tentative: a full-stack AI job-search copilot, built with your web skills plus everything above
  • Deployed, with a README, a demo video and eval results
We'll confirm the idea together after Module 3.
