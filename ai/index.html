How the course works

Every session has the same three parts: read, learn with Claude, build.

  1. Read (30–40 min): the book section listed for the session. Fine to do before the session, in a spare half hour.
  2. Learn with Claude (≈ 40 min): a short lesson that connects the reading to current Python and tools, a quiz with instant feedback, and your questions. Ask about anything in the book you didn't get.
  3. Build (≈ 60–70 min): add to the running project. Each module still ends with a project.

Books age; docs don't. Fluent Python was tested on Python 3.10 and you're on 3.14, so lessons point out what changed (for example newer generic syntax and lazy annotations). Fluent Python's own preface says it's hard for beginners, so we read only the sections that match what we're building. Raschka's code runs on a regular laptop, and the official notebooks are at rasbt/LLMs-from-scratch. When a book and the official docs disagree, the docs win.

Modules

Plan updated 2026-10-12: books added, ~5 months (LR-0010). 📖 FP = Fluent Python (section names, with PDF page numbers) · 📗 LLM = Raschka (section numbers).

1 · Finish Python basics

3 sessions · ≈ 1.5 weeks
  1. Built-ins and comprehensions + errors and exceptions · 📖 FP ch. 2 “List Comprehensions and Generator Expressions” (PDF pp. 55–60)
  2. Files and JSON + modules, packages and uv · 📖 FP ch. 4 “Handling Text Files” (PDF pp. 161–170)
  3. Build: a small job-radar CLI that reads postings from a JSON file and counts skills

2 · Python for web and APIs

4 sessions · ≈ 2 weeks
  • Classes, special methods and dataclasses · 📖 FP ch. 1 “The Python Data Model” (PDF pp. 33–48) + ch. 5 “Overview of Data Class Builders”, “Type Hints 101”, “More About @dataclass” (PDF pp. 194–198, 203–220)
  • Type hints and Pydantic · 📖 FP ch. 8 from “About Gradual Typing” to “Types Are Defined by Supported Operations” (PDF pp. 284–296)
  • httpx and async/await · 📖 FP ch. 21 from “A Few Definitions” to “Asynchronous Context Managers” (PDF pp. 807–817; it uses HTTPX too)
  • FastAPI · 📖 FP ch. 9 from “Decorators 101” to “Implementing a Simple Decorator” (PDF pp. 334–350). FastAPI routes are decorators.
No separate project. The FastAPI service is built in the Module 3 project.

3 · LLM fundamentals (the core of the job)

11 sessions · ≈ 5.5 weeks
  • What an LLM is · 📗 LLM ch. 1 (all)
  • Tokens and embeddings from the inside · 📗 LLM ch. 2, §2.1–2.5 (build a tokenizer, then use BPE with tiktoken). §2.6–2.8 are read again at the start of Module 6.
  • First local model call (Ollama / LM Studio) and first free-tier API call
  • Prompting and structured output (with Pydantic)
  • Streaming responses · 📖 FP ch. 17 from “Iterables Versus Iterators” to “When to Use Generator Expressions” (PDF pp. 629–645)
  • Tool calling
  • Embeddings and vector search, then RAG
  • Evals: proving your app works (2 sessions)
Project (2 sessions): a FastAPI service that extracts skills from job postings and answers questions about them, with an eval report.

4 · LangChain and LangGraph

4 sessions · ≈ 2 weeks
  • LangChain 1.x: models, messages, tools and create_agent (docs)
  • LangGraph: state, memory, human-in-the-loop
  • MCP, briefly
Project: add an agent to the Module 3 service.

5 · Capstone (protected)

8 sessions · ≈ 4 weeks · ships ≈ end of January 2027
  • Tentative: a full-stack AI job-search copilot, built with your web skills on top of Modules 3–4
  • Deployed, with a README, a demo video and eval results. Start applying once it ships.
Confirm the idea together at the end of Module 3. This module is never cut.

6 · Build an LLM from scratch (Raschka, in order)

13 sessions · ≈ 6.5 weeks · runs on your Mac
  1. PyTorch basics · 📗 appendix A, §A.1–A.8
  2. Data pipeline · 📗 §2.6–2.8 (sliding window, token and position embeddings)
  3. Self-attention · 📗 §3.1–3.4
  4. Causal and multi-head attention · 📗 §3.5–3.6
  5. Layer norm, GELU feed-forward, shortcuts · 📗 §4.1–4.4
  6. Transformer block, GPT model, generating text · 📗 §4.5–4.7
  7. Evaluating and training · 📗 §5.1–5.2
  8. Decoding strategies, saving, loading OpenAI's GPT-2 weights · 📗 §5.3–5.5
  9. Classification fine-tuning, part 1 · 📗 §6.1–6.5
  10. Classification fine-tuning, part 2: loss, accuracy, spam classifier · 📗 §6.6–6.8 (this covers train/val/test splits and metrics)
  11. Instruction fine-tuning, part 1 · 📗 §7.1–7.5
  12. Instruction fine-tuning, part 2: train, extract, evaluate · 📗 §7.6–7.9
  13. LoRA, then publish your model to Hugging Face · 📗 appendix E
Project: my-gpt, your own GPT repo with a README that explains each part. It's strong interview material. Exercise solutions are in appendix C. Try each exercise before you look.

Buffer and optional

3 buffer sessions
  • Buffer for missed weeks. If unused: scikit-learn classic ML (2 sessions) or 📗 appendix D (learning-rate warmup, cosine decay, gradient clipping).
  • Later: more of Fluent Python. Read ch. 1 first, then any part in any order (the author's advice).

If you fall behind: cut order

  1. Use the 3 buffer sessions first.
  2. 📖 Fluent Python readings become skims. The lessons still cover what you need.
  3. Module 4 shrinks to one agent session.
  4. Module 6 drops ch. 7 (instruction fine-tuning) and keeps appendix A, ch. 2–6 and LoRA.
  5. Never cut: the capstone and evals. They are what get you hired.
