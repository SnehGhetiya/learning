# Starting point: experienced web developer, zero Python/AI

The learner has web development experience (so they already know programming fundamentals, HTTP, JSON, package managers and the terminal), but has never written Python or worked with AI/ML. This means lessons can skip "what is a variable/loop/function" and teach Python by **mapping from JS/npm equivalents**. New ideas that have no web analogue (tensors, gradients, embeddings, evaluation) need to be taught from scratch, with more scaffolding.

**Evidence**: Self-reported at the start of the course (2026-09-23).

**Implications**: Phase 1 (Python) can move quickly and focus on idioms and tooling rather than basics. The capstone should use the learner's frontend skills so the effort goes into the AI parts.
