Warm-up: from Topics 1 and 2

What does this print?

name = "ada"
name.title()
print(name)
Strings are immutable. .title() returned 'Ada', but nothing kept it. To keep it, write name = name.title().

What does this print?

print("3" * 2)
"3" is a string, so * repeats it: 33. With the number 3 * 2, you'd get 6.

1 · A new type: bool

A boolean (bool) has only two possible values: True and False. It's the fourth type you've met, after int, float and str.

Watch out, JavaScript habit In Python they're capitalised. true in lowercase is just an unknown name: 
NameError: name 'true' is not defined. Did you mean: 'True'?

Comparisons produce booleans

OperatorMeaningExampleResult
==equal to4 == 4.0True
!=not equal to10 != 3True
< >less / greater than5 > 3True
<= >=…or equal3 >= 5False
  • = assigns, and == compares. Mixing them up is the classic bug. Python has no ===: == already compares values sensibly (docs).
  • String comparison is case-sensitive: "AI" == "ai" is False. Use .lower() on both sides when case shouldn't matter.
  • Comparisons can be chained as in maths: 5 <= hours <= 40 means "hours is between 5 and 40".

in: does the text contain this?

>>> "rag" in "python, rag, evals"
True

It's like JavaScript's .includes(). You'll use in constantly, and in Topic 4 it works on lists too.

Combining conditions: and, or, not

JS &&, || and ! become plain English words in Python.

See the boolean operations docs. Use parentheses to make the grouping clear: not (a or b).

2 · if, elif, else

This is where your program starts making choices. It's also your first block: a group of lines that belong together.

weeks = 30

if weeks > 52:
    print("over a year")
elif weeks > 26:
    print("steady")
else:
    print("fast")
  • Python checks each condition top to bottom, runs the block of the first one that's True, then skips the rest. Here it prints steady.
  • elif means "else if". You can have as many as you like, or none.
  • else is optional. It runs when nothing above matched.
Indentation is the syntax Python has no { }. A line ending in : starts a block, and the block is every line indented 4 spaces below it. The block ends when the indentation goes back out. In Sublime Text, make sure View → Indentation → Indent Using Spaces is ticked and the tab width is 4. Then Tab inserts 4 spaces.

The three errors you'll hit while learning this, and what they look like in 3.14:

MistakePython says
Forgot the : in if x > 3SyntaxError: expected ':'
Didn't indent the line after the ifIndentationError: expected an indented block after 'if' statement on line 2
Wrote if x = 5:SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Blocks inside blocks

A block can contain another if. Each level indents 4 more spaces. You'll see this in the build below: the whole report sits inside an else:, so it only runs when the input is valid.

Truthiness: values that count as False

An if doesn't need an actual True or False. Python treats 0, 0.0 and the empty string "" as false, and almost everything else as true (truth value testing). This makes checks like this read naturally:

name = input("Your name: ").strip()
if not name:
    print("You didn't type a name!")

Practice: recall, don't reread

1. What does this print?

print("AI" == "ai")
String comparison is case-sensitive. Use "AI".lower() == "ai" when case shouldn't matter.

2. What does this print?

print("rag" in "python, rag, evals")
in checks whether one string appears inside another, and "rag" does.

3. What does this print?

print(not (4 > 2 or 1 > 2))
Work from the inside out. 4 > 2 is True, so True or False is True, and not True is False.

4. What does this print?

print(3 < 7 < 5)
A chained comparison means 3 < 7 and 7 < 5. The second part is False, so the whole thing is False.

5. What does this print?

hours = 8
if hours > 20:
    print("intense")
elif hours > 5:
    print("medium")
elif hours > 2:
    print("light")
else:
    print("minimal")
The first condition that's True wins: 8 > 20 is no, and 8 > 5 is yes, so it prints medium. Python never checks hours > 2, even though it's also true.

6. What does this print?

name = ""
if name:
    print("hello")
else:
    print("empty")
An empty string is falsy, so the else block runs and prints empty.

7. What happens when Python reads if hours = 10:?

= assigns, and it isn't allowed in an if condition. Python even suggests the fix: "Maybe you meant '==' …?"

8. How does Python know which lines belong to an if?

The : opens the block, and the indentation (4 spaces) defines it. There are no braces or end keyword.

Answer from memory

How do you write JavaScript's a && !b in Python?

a and not b

What's the difference between an if/elif chain and two separate ifs?

An if/elif/else chain runs at most one block, the first that's true. Separate ifs are each checked independently, so several can run.

Name three values that count as false in an if.

False, 0 (and 0.0), and the empty string "".
