What Python is

Python is a programming language. The Python interpreter is the program that reads your Python code and runs it, line by line, from top to bottom. There's no build or compile step: you write code and run it straight away.

If you've used Node.js: python3 works like node. Running it with no file gives an interactive prompt, and running it with a file runs that file.

You can talk to the interpreter in two ways, and you'll use both all the time:

  1. Interactive mode (the REPL): type one line, and Python answers immediately. It's great for trying things out.
  2. Script files: write code in a .py file and run the whole file. This is how real programs are written.

1 · Interactive mode

  1. Open a terminal and check your Python version: 
    $ python3 --version
Python 3.14.7
  2. Start interactive mode by typing python3 on its own. You'll see a >>> prompt, which means Python is waiting for you. In Python 3.14 the prompt colors your code as you type (What's New in 3.14). 
    $ python3
>>> 2 + 3
5
  3. Now try each of these yourself. Before you press Enter, guess the answer. Guessing first is what makes it stick. 
    >>> 7 / 2
3.5
>>> 7 // 2
3
>>> 7 % 2
1
>>> 2 ** 10
1024
  4. Leave interactive mode by typing exit() and pressing Enter, or press Ctrl+D.

Numbers and arithmetic

Python has two main kinds of numbers (tutorial §3.1.1):

  • int (integer): whole numbers such as 7, -3 or 1024.
  • float (floating-point number): numbers with a decimal point, such as 3.5 or 4.0.

Watch out, JavaScript habit In JavaScript, // starts a comment. In Python, // is floor division. Comments in Python start with #.

Want to see this for yourself? Try 0.1 + 0.2. You'll get 0.30000000000000004, exactly as in JavaScript. This is normal for floats in every language (tutorial §15).

Two details worth knowing:

  • Python's int has no size limit. 2 ** 100 gives the exact answer, 1267650600228229401496703205376.
  • Parentheses work as in maths: (2 + 3) * 4 is 20.

Variables

A variable is a name that refers to a value. You create one with =. Python has no keyword such as let or const: you just write the name.

>>> hours_per_week = 4
>>> hours_per_week * 52
208

Python names use snake_case: lowercase words joined by underscores (PEP 8, Python's style guide). Topic 2 covers variables in depth.

2 · Your first script

Interactive mode forgets everything when you exit. To keep your code, save it in a file.

  1. Make a folder for all your topic exercises and open a new file in Sublime Text: 
    $ mkdir -p ~/Music/learning/ai/practice
$ cd ~/Music/learning/ai/practice
$ subl 01_study_plan.py
  2. Type this in yourself rather than pasting it. Typing it builds the habit.

    01_study_plan.py

    # Study plan calculator: how long will this course take me?
hours_per_week = 4
total_hours = 180  # a rough estimate for the whole course

weeks = total_hours / hours_per_week
print("Weeks to finish:", weeks)
print("Whole months:", weeks // 4)
    Save the file (Ctrl+S).
  3. Run it: 
    $ python3 01_study_plan.py
Weeks to finish: 45.0
Whole months: 11.0
  4. Break it on purpose. Delete the last ) on the final line, save, and run again. You'll see your first error: 
      File "01_study_plan.py", line 7
    print("Whole months:", weeks // 4
         ^
SyntaxError: '(' was never closed
    Read it from the bottom up. The last line says what went wrong (a SyntaxError: the code isn't valid Python). The lines above say where: which file, which line, with a ^ pointing at the spot. Put the ) back and run it again.

What's new in that file

# starts a comment. Python ignores everything from # to the end of the line. Comments are notes for humans.

print() shows output. In interactive mode, Python shows every result automatically. A script shows nothing unless you print it. print can take several values separated by commas and puts a space between them (docs).

Why 45.0 and not 45? Because / always gives a float, even when the division comes out even. Then weeks // 4 floor-divides a float, so the result is also a float: 11.0.

Practice: recall, don't reread

Answer from memory. If it feels a bit hard, that's good: the effort of remembering is what makes it stick.

1. What does Python show?

>>> 8 / 2
/ always returns a float, even when the division is exact, so the answer is 4.0, not 4.

2. What does Python show?

>>> 17 // 5
17 ÷ 5 = 3.4, and floor division drops the fraction, giving 3. Both inputs are ints, so the result is an int too.

3. What does Python show?

>>> 10 % 3
10 ÷ 3 = 3 with 1 left over. % gives the remainder, 1. It's often used to check whether a number is even: n % 2 == 0.

4. What does Python show?

>>> 2 ** 3
** is power: 2 × 2 × 2 = 8.

5. A script file contains only this line: 3 + 4. You run it with python3. What happens?

Python calculates 7 and then throws it away. Only interactive mode shows results automatically. In a script, you need print(3 + 4).

6. In Python, what does // mean?

// is floor division: 7 // 2 is 3. Comments use #, and / is the division that keeps the decimals.

Answer from memory

What are the two ways to run Python code?

Interactive mode (type python3 and get a >>> prompt) and script files (python3 file.py).

What's the difference between int and float?

int is a whole number (7). float has a decimal point (3.5, 4.0). / always produces a float.

An error message appears. Which line do you read first?

The last line: it names the error type and what went wrong. The lines above it show where the error happened.
