1 · Variables, properly

A variable is a name that points to a value. The = sign means "make this name point to this value". It's not the "equals" from maths. So this is valid:

>>> hours = 4
>>> hours = hours + 2
>>> hours
6

Python evaluates the right side first (4 + 2, which is 6), then makes hours point to the result.

Naming rules

  • Names may use letters, digits and _, but cannot start with a digit: week2 is fine, but 2nd is a SyntaxError.
  • Names are case-sensitive: hours and Hours are different names.
  • The convention is snake_case: hours_per_week, not hoursPerWeek (PEP 8).

Python 3.14's error messages often suggest a fix. Read them; they're on your side.

If you use a name that doesn't exist, perhaps because of a typo, you get a NameError:

NameError: name 'hours_per_wek' is not defined. Did you mean: 'hours_per_week'?

Every value has a type

type() tells you what kind of value something is (docs). So far you know int and float. Text is the third type, str:

>>> type(4)
<class 'int'>
>>> type(4.0)
<class 'float'>
>>> type("hello")
<class 'str'>

A variable has no fixed type. x = 4 and then x = "four" is allowed, just as in JavaScript.

2 · Strings

A string (str) is a piece of text. You write one in "double" or 'single' quotes; both mean the same thing.

>>> print("She said \"hi\"")   # \" puts a quote inside a string
She said "hi"
>>> print('It\'s fine')        # or \' inside single quotes
It's fine
>>> print("line1\nline2")      # \n means "new line"
line1
line2

String methods

A method is a function that belongs to a value. You call it with a dot: value.method(). Here are the most useful ones (full list):

CodeResult
" AI Engineer ".strip()'AI Engineer': removes spaces at both ends
"ai engineer".upper()'AI ENGINEER'
"AI Engineer".lower()'ai engineer'
"ai engineer".title()'Ai Engineer': capitalises each word
"python,rag".replace(",", " + ")'python + rag'
The most common beginner bug Strings can never be changed ("immutable"). Methods return a new string and leave the original alone: 
title = "ai engineer"
title.upper()          # makes 'AI ENGINEER'... and throws it away
title = title.upper()  # ✓ keep the result by assigning it

You can chain methods, and they run left to right: " ada lovelace ".strip().title() gives 'Ada Lovelace'.

3 · f-strings: putting values into text

Put an f before the opening quote, and anything inside { } is evaluated as Python code (docs):

>>> hours = 4
>>> f"I study {hours} hours, which is {hours * 60} minutes"
'I study 4 hours, which is 240 minutes'

Add :.1f after a value to show it with 1 decimal place, or :.0f for none (format spec docs):

>>> f"{180 / 7:.1f} hours"
'25.7 hours'

Python 3.14 also added t-strings, t"..." (PEP 750). They're for advanced uses, such as safely building HTML or SQL. For everyday work, f-strings are what you want.

That's the fix for your double space: print(f"Weeks to finish: {weeks}") is a single string, so you control every character.

input(): asking the user

input("question") shows the question, waits for the user to type and press Enter, and returns what they typed (docs). It always returns a str, even if the user types a number. To do maths with it, convert it first: float(input("Hours: ")).

Practice: recall, don't reread

1. What does this print?

title = "ai engineer"
title.upper()
print(title)
Strings are immutable. title.upper() created 'AI ENGINEER', but nothing kept it, so title is unchanged: ai engineer. The fix is title = title.upper().

2. What does this print?

print("4" + "4")
Both are strings, so + joins them into 44. It's text, not the number 8.

3. What happens with "4" + 4 in Python?

Python won't mix str and int with +. You choose explicitly: int("4") + 4 gives 8, and "4" + str(4) gives '44'.

4. A user runs age = input("Age: ") and types 30. What is the type of age?

input() always returns a str, here '30'. Convert it with int(age) before doing maths.

5. What does this print?

print(f"{10 / 3:.2f}")
10 / 3 is 3.3333…, and :.2f shows 2 decimal places: 3.33.

6. What does this print?

print(len("  hi  ".strip()))
.strip() runs first and gives 'hi', whose length is 2. Without the strip, it would be 6, because spaces count as characters.

Answer from memory

How do you put the value of hours into a sentence?

With an f-string: f"I study {hours} hours".

Why do you need float(input(...)) rather than just input(...)?

input() always returns a str, and you can't do maths with text, so you convert it to a number first.

You wrote name.strip(), but name still has spaces. Why?

Strings are immutable. The method returned a new string that you didn't keep. Write name = name.strip().
