1 · Defining and calling a function

A function is a named block of code. You define it once with def, then call it as many times as you like (docs).

def greet(name):                # def, a name, parameters in ( ), then a colon
    message = f"Hi {name}!"     # the body is indented, like if and for
    return message              # hand a value back to the caller

text = greet("Ada")             # call it: "Ada" goes into name
print(text)                     # Hi Ada!
  • A parameter is the name in the definition (name). An argument is the value you pass in the call ("Ada").
  • Function names follow the same rules as variables: snake_case, ideally a verb: ask_hours, count_words.
  • PEP 8 puts two blank lines before and after each top-level function.

Python runs the file top to bottom. def is a statement that creates the function when it runs, so define your functions above the code that calls them.

2 · return

return sends a value back and ends the function immediately. Inside a loop, it ends the loop too.

def ask_hours():
    while True:
        hours = float(input("Hours per week (1-80): "))
        if 1 <= hours <= 80:
            return hours        # leaves the loop AND the function: no break needed
        print("Please enter a number from 1 to 80.")

No return? You get None

A function that ends without return still returns something: None (docs). It's like a JS function returning undefined.

Trap: print is not return print() shows text on the screen for a human. return hands a value to the code that called the function. If you write def total(...): print(sum), then x = total(...) leaves x as None. Rule of thumb: most functions return, and only a few "show it" functions print.

Returning several values

Return several values separated by commas. Python packs them into one tuple, and the caller unpacks it, just as in Topic 5:

def summarise(modules):
    total = 0
    top_hours = 0
    for module in modules:
        total += module["hours"]
        if module["hours"] > top_hours:
            top_hours = module["hours"]
    return total, top_hours     # one tuple: (total, top_hours)

total, top_hours = summarise(modules)   # unpack: 270, 45

3 · Default and keyword arguments

A parameter can have a default value, which is used when the caller leaves it out (docs):

def print_line(char="-", width=40):
    print(char * width)

print_line()                # ----------------------------------------
print_line("=")             # ========================================
print_line(width=10)        # ----------  (keyword argument: skip char, set width)
print_line("*", width=5)    # *****
  • A keyword argument (width=10) names the parameter it's for, so the order doesn't matter and the call reads clearly. You've used these already: sorted(x, reverse=True).
  • In a call, positional arguments come first and keyword arguments after them. print_line(width=5, "*") is a SyntaxError.
  • Parameters with defaults come after the ones without: def f(text, limit=3):.
  • Python checks keyword names. greet(nme="Ada") gives TypeError: greet() got an unexpected keyword argument 'nme'. Did you mean 'name'?
Trap: never use a list or dict as a default A default is created once, when def runs, not on each call. So def add(item, items=[]): keeps sharing the same list, and it grows every time you call it (docs warning). Instead, use items=None, then if items is None: items = [] inside the function.

4 · Scope: variables live inside their function

A variable you create inside a function is local. It exists only while the function runs, like let inside a JS function.

def make_total():
    total = 270

make_total()
print(total)     # NameError: name 'total' is not defined

A function can read a variable from the main file, but if it assigns to that name anywhere, Python treats the name as local throughout the function:

count = 0
def add_one():
    count += 1   # UnboundLocalError: cannot access local variable 'count'
                 # where it is not associated with a value

The clean fix is the habit this whole topic is about: pass data in as arguments, send results out with return.

def add_one(count):
    return count + 1

count = add_one(count)

Python has a global keyword to get around this. Avoid it. Functions that only use their inputs and outputs are easy to test, and that will matter when you write evals in Module 3.

5 · Docstrings

A string on the first line of the body is a docstring: it documents the function (docs). Editors show it on hover, and help(ask_hours) prints it.

def ask_hours():
    """Keep asking until the answer is between 1 and 80, then return it."""

Why this matters for AI work: in Module 3, tool calling means an LLM decides to call one of your Python functions. The function's name, parameters and docstring are what the model reads to decide when and how to call it. Clear functions make good tools.

1. What does this print?

def double(n):
    return n * 2

print(double(5))
5 goes into n, and the function returns 10.

2. What does this print?

def double(n):
    n * 2

print(double(5))
No return, so the function returns None. The n * 2 is calculated and thrown away.

3. What does this print? (Two lines.)

def say_hi():
    print("hi")

result = say_hi()
print(result)
Calling it prints hi. It returns nothing, so result is None.

4. What does this print?

def line(char="-", width=40):
    return char * width

print(line("*", width=3))
char is "*" and width is 3, so you get "***".

5. What does this print?

def first_even(numbers):
    for n in numbers:
        if n % 2 == 0:
            return numbers.index(n)
    return -1

print(first_even([3, 8, 5, 6]))
8 is the first even number, at index 1. return stops the loop right there, so 6 is never checked.

6. What does this print?

def stats():
    return 270, 45

total, top = stats()
print(top)
The function returns the tuple (270, 45), and unpacking puts 45 into top.

7. What happens here?

def setup():
    level = 3

setup()
print(level)
level is local to setup. To get it out, return level and catch it: level = setup().

Answer from memory

What's the difference between print and return in a function?

print shows text on screen and gives the caller nothing (None). return hands a value back to the caller and ends the function.

How does a function give back two values?

return a, b returns one tuple. The caller unpacks it: a, b = f().

Why shouldn't a default value be []?

Defaults are created once, when def runs. Every call would share and grow the same list. Use None and create the list inside.
