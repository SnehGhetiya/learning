# AI Engineer learning workspace

This folder is a teaching workspace for one learner: a web developer becoming an AI engineer. Python topics 1–6 are done.

## Before teaching, reviewing practice code or answering "what's next"

Read these first, in order:

1. `MISSION.md`: why they're learning, success criteria, constraints.
2. `learning-records/0010-current-plan-books-ai-projects-5-months.md`: **the** current plan and the reasons behind it.
3. `NOTES.md`: learner preferences, environment, course structure, where the book PDFs are.
4. `index.html`: the session-by-session plan with the exact book reading for each session. The first session not yet linked to a lesson is the next one.
5. The highest-numbered topic records in `learning-records/`: what they've just learned and what to revisit.

For lessons, use the `mattpocock-skills:teach` skill; it defines the lesson, record and reference formats.

## Standing rules

- Every session is **read (book) → learn with Claude (lesson + quiz) → build (project)**, about 2.5 h, with 5–6 h/week in total.
- Books: *Fluent Python* 2nd ed. (selected sections only) and Raschka's *Build a LLM (From Scratch)* (in order). PDFs are in `~/Downloads`. Cite exact sections.
- Check every tool, API and version against current official docs. When a book and the docs disagree, teach the docs and explain the difference.
- Free tools only. No NVIDIA GPU.
- When the plan changes, update the plan record (LR-0010) and `index.html` instead of adding competing plan records.
