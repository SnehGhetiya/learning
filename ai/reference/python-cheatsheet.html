Basics

  • int is a whole number, 7. float has a decimal point, 3.5.

Topic 2 · Variables and strings

Variables

hours = 4
hours = hours + 2      # right side first, then the name points to 6
type(hours)            # <class 'int'>. Types so far: int, float, str
  • Names use letters, digits and _, can't start with a digit, and are case-sensitive. Use snake_case.
  • Typo in a name → NameError (Python often suggests "Did you mean…").

f-strings and conversion

f"{hours} hours = {hours * 60} min"   # any expression inside { }
f"{180 / 7:.1f}"                      # '25.7' (1 decimal place)

hours = float(input("Hours: "))      # input() ALWAYS returns str
  • "4" + 4 → TypeError (JS would give "44"). int("ten") → ValueError.

if weeks > 52:            # colon opens a block
    print("over a year")  # 4-space indent = inside the block

Topic 4 · Lists and loops

skills = ["python", "rag", "evals"]
skills[0]  skills[-1]        # 'python'  'evals' (index starts at 0)
skills[0:2]                  # ['python', 'rag'] (up to, not including, 2)
skills.append("pytorch")     # lists are MUTABLE: change in place
skills.remove("rag")
"rag" in skills              # whole-item check
sorted(skills)               # returns a new list; skills.sort() returns None
"head of ai".split()         # ['head', 'of', 'ai']
", ".join(skills)            # 'python, evals, pytorch'
for skill in skills:         # once per item
    print(skill)

total = 0                    # accumulator: start before the loop...
for n in [3, 4, 5]:
    total += n               # ...add inside it (+= means total = total + n)

for i in range(len(skills)): # range(3) → 0, 1, 2
    print(i + 1, skills[i])

while True:                  # repeat until...
    answer = input("> ")
    if answer:
        break                # ...break exits the loop
  • "ai" in text matches letters anywhere. "ai" in text.split() matches whole words.
  • A bad index gives IndexError: list index out of range. A stuck loop: press Ctrl+C.
  • None is Python's "no value" (like JS null).
